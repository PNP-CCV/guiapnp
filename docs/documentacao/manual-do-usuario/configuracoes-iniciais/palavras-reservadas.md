# Palavras Reservadas

Palavra reservada é uma palavra que não pode aparecer no nome de um curso.
Ao gerar as inconsistências, a plataforma confere o nome de cada curso ativo
e, se encontrar nele uma palavra reservada — no singular ou no plural, como
palavra inteira e sem diferença entre maiúsculas e minúsculas —, marca o
curso com a inconsistência **Nome do Curso** (ver
[Inconsistências de Ensino]({{site.baseurl}}/documentacao/manual-do-usuario/inconsistencias/inconsistencias-de-ensino)).

Esta tela está disponível para os perfis Registrador Acadêmico, Executor
Acadêmico, Administrador, Gestor CCV, Suporte CCV, Pesquisador
Institucional e Reitor.
Cadastrar, editar e excluir palavras é só do Administrador e do Gestor CCV;
os demais perfis apenas consultam.

## Ver as palavras cadastradas

Em **Cadastros Gerais → Palavras Reservadas**, a plataforma lista as
palavras já cadastradas, com a forma no singular e no plural de cada uma. O
bloco **Filtros**, acima da lista, permite buscar por palavra-chave. Na
coluna **Ação**, os ícones abrem a edição e a exclusão da palavra.

![Listagem de palavras reservadas]({{site.baseurl}}/assets/img/docs/manual-do-usuario/configuracoes-iniciais/palavras-reservadas/lista.png)

## Cadastrar uma palavra

O botão **Cadastrar**, no canto superior direito da lista, abre o
formulário de cadastro. Singular e Plural são obrigatórios. A palavra nova
passa a valer na próxima geração de inconsistências.

![Formulário de cadastro de palavra reservada]({{site.baseurl}}/assets/img/docs/manual-do-usuario/configuracoes-iniciais/palavras-reservadas/cadastrar.png)
