# Identidades de Gênero

A identidade de gênero é uma das informações de cada matrícula. Esta tela
mantém a lista de opções aceitas para ela. Matrícula atendida sem
identidade de gênero é marcada com a inconsistência **Identidade de
Gênero** (ver
[Inconsistências de Ensino]({{site.baseurl}}/documentacao/manual-do-usuario/inconsistencias/inconsistencias-de-ensino)).

Esta tela está disponível para os perfis Registrador Acadêmico, Executor
Acadêmico, Administrador, Gestor CCV, Suporte CCV, Pesquisador
Institucional e Reitor.
Cadastrar, editar e excluir identidades é só do Administrador e do Gestor
CCV; os demais perfis apenas consultam.

## Ver as identidades cadastradas

Em **Cadastros Gerais → Identidades de Gênero**, a plataforma lista as
identidades já cadastradas, pelo nome. O bloco **Filtros**, acima da lista,
permite buscar por palavra-chave. Na coluna **Ação**, os ícones abrem a
edição e a exclusão da identidade.

![Listagem de identidades de gênero]({{site.baseurl}}/assets/img/docs/manual-do-usuario/configuracoes-iniciais/identidades-de-genero/lista.png)

## Cadastrar uma identidade

O botão **Cadastrar**, no canto superior direito da lista, abre o
formulário de cadastro. O nome é obrigatório.

![Formulário de cadastro de identidade de gênero]({{site.baseurl}}/assets/img/docs/manual-do-usuario/configuracoes-iniciais/identidades-de-genero/cadastrar.png)

> **⚠️ Excluir uma identidade em uso**
>
> As matrículas que usavam a identidade excluída ficam sem identidade de
> gênero — e, se atendidas, passam a ser marcadas com a inconsistência
> **Identidade de Gênero**.
