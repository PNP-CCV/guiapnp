# Fontes de Financiamento

Esta tela mantém a lista de fontes de financiamento. Cada
[programa]({{site.baseurl}}/documentacao/manual-do-usuario/configuracoes-iniciais/programas) é ligado a uma ou mais fontes, e cada ciclo pode
indicar a sua.

Esta tela está disponível para os perfis Registrador Acadêmico, Executor
Acadêmico, Administrador, Gestor CCV, Suporte CCV, Pesquisador
Institucional e Reitor.
Cadastrar, editar e excluir fontes aparece só para o Administrador e o
Gestor CCV; os demais perfis apenas consultam.

## Ver as fontes cadastradas

Em **Cadastros Gerais → Fontes de Financiamento**, a plataforma lista as
fontes já cadastradas, pelo nome. O bloco **Filtros**, acima da lista,
permite buscar por palavra-chave. Na coluna **Ação**, os ícones abrem a
edição e a exclusão da fonte.

![Listagem de fontes de financiamento]({{site.baseurl}}/assets/img/docs/manual-do-usuario/configuracoes-iniciais/fontes-de-financiamento/lista.png)

## Cadastrar uma fonte

O botão **Cadastrar**, no canto superior direito da lista, abre o
formulário de cadastro. O nome é obrigatório.

![Formulário de cadastro de fonte de financiamento]({{site.baseurl}}/assets/img/docs/manual-do-usuario/configuracoes-iniciais/fontes-de-financiamento/cadastrar.png)

> **⚠️ Excluir uma fonte em uso**
>
> A fonte excluída sai dos programas ligados a ela, e os ciclos que a
> indicavam ficam sem fonte de financiamento.
