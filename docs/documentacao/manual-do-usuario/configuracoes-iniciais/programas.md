# Programas

Esta tela mantém a lista de programas. Cada programa é ligado a uma ou
mais [fontes de financiamento]({{site.baseurl}}/documentacao/manual-do-usuario/configuracoes-iniciais/fontes-de-financiamento), cada ciclo pode
indicar o seu, e as
[regras de associação a programas]({{site.baseurl}}/documentacao/manual-do-usuario/configuracoes-iniciais/regras-de-associacao-a-programas)
apontam para eles.

Esta tela está disponível para os perfis Registrador Acadêmico, Executor
Acadêmico, Administrador, Gestor CCV, Suporte CCV, Pesquisador
Institucional e Reitor.
Cadastrar, editar e excluir programas aparece só para o Administrador e o
Gestor CCV; os demais perfis apenas consultam.

## Ver os programas cadastrados

Em **Cadastros Gerais → Programas**, a plataforma lista os programas já
cadastrados, com o nome e as fontes de financiamento de cada um. O bloco
**Filtros**, acima da lista, permite buscar por palavra-chave. Na coluna
**Ação**, os ícones abrem a edição e a exclusão do programa.

![Listagem de programas]({{site.baseurl}}/assets/img/docs/manual-do-usuario/configuracoes-iniciais/programas/lista.png)

## Cadastrar um programa

O botão **Cadastrar**, no canto superior direito da lista, abre o
formulário de cadastro. O nome é obrigatório, e é preciso escolher ao menos
uma fonte de financiamento — o campo aceita várias.

![Formulário de cadastro de programa]({{site.baseurl}}/assets/img/docs/manual-do-usuario/configuracoes-iniciais/programas/cadastrar.png)

> **⚠️ Excluir um programa em uso**
>
> Os ciclos que indicavam o programa excluído ficam sem programa, e ele sai
> das regras de associação a programas em que aparecia.
