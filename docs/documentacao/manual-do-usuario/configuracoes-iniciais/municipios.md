# Municípios

O município é a cidade de cada [unidade]({{site.baseurl}}/documentacao/manual-do-usuario/configuracoes-iniciais/unidades): é por ele que a
unidade tem a sua UF. Esta tela mantém a lista de municípios, com o código
e a microrregião de cada um.

Esta tela está disponível só para o perfil Administrador, que também
cadastra e edita municípios.

## Ver os municípios cadastrados

Em **Cadastros Gerais → Municípios**, a plataforma lista os municípios com
o nome, o código, a microrregião e a UF. O bloco **Filtros**, acima da
lista, permite buscar por palavra-chave. Na coluna **Ação**, o ícone abre
a edição do município; a tela não exclui municípios.

![Listagem de municípios]({{site.baseurl}}/assets/img/docs/manual-do-usuario/configuracoes-iniciais/municipios/lista.png)

## Cadastrar um município

O botão **Cadastrar**, no canto superior direito da lista, abre o
formulário de cadastro. Nome, Código e Microrregião são obrigatórios; o
código tem no máximo 6 caracteres.

![Formulário de cadastro de município]({{site.baseurl}}/assets/img/docs/manual-do-usuario/configuracoes-iniciais/municipios/cadastrar.png)
