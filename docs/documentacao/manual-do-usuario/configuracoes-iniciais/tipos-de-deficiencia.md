# Tipos de Deficiência

O tipo de deficiência é uma das informações de cada matrícula. Esta tela
mantém a lista de opções aceitas para ela. A plataforma cruza essa
informação com a forma de ingresso: matrícula que entrou por cota reservada
a pessoa com deficiência e está como **Não possui deficiência** aparece
como inconsistente na inconsistência **Tipo de Deficiência** (ver
[Inconsistências de Ensino]({{site.baseurl}}/documentacao/manual-do-usuario/inconsistencias/inconsistencias-de-ensino)).

Esta tela está disponível para os perfis Registrador Acadêmico, Executor
Acadêmico, Administrador, Gestor CCV, Suporte CCV, Pesquisador
Institucional e Reitor.
Cadastrar, editar e excluir tipos é só do Administrador e do Gestor CCV; os
demais perfis apenas consultam.

## Ver os tipos cadastrados

Em **Cadastros Gerais → Tipos de Deficiência**, a plataforma lista os tipos
já cadastrados, pelo nome. O bloco **Filtros**, acima da lista, permite
buscar por palavra-chave. Na coluna **Ação**, os ícones abrem a edição e a
exclusão do tipo.

![Listagem de tipos de deficiência]({{site.baseurl}}/assets/img/docs/manual-do-usuario/configuracoes-iniciais/tipos-de-deficiencia/lista.png)

## Cadastrar um tipo

O botão **Cadastrar**, no canto superior direito da lista, abre o
formulário de cadastro. O nome é obrigatório.

![Formulário de cadastro de tipo de deficiência]({{site.baseurl}}/assets/img/docs/manual-do-usuario/configuracoes-iniciais/tipos-de-deficiencia/cadastrar.png)

## Excluir um tipo

A plataforma não exclui um tipo de deficiência que alguma matrícula ainda
use.
