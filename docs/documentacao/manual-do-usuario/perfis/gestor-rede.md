# Gestor Rede

O Gestor Rede não tem tela nesta plataforma: nada no menu, e o Painel
aparece sem cards. O acesso deste perfil é ao portal da PNP, que este
manual não cobre.

## O que você enxerga

O perfil grava uma instituição, que identifica a sua rede, mas o acesso
não se limita a ela: é nacional.
