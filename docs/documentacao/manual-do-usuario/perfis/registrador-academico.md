# Registrador Acadêmico

O Registrador Acadêmico acompanha os dados de ensino da sua unidade —
cursos, matrículas, ciclos e alunos — e trata as inconsistências de
ensino: resolve, conclui e restaura. Também cadastra pessoas e pode
atribuir a elas o perfil Executor Acadêmico, e só esse.

## O que você enxerga

O perfil é vinculado a uma unidade. As telas mostram os dados dessa
unidade.

## Suas telas

Estas são as telas que aparecem no menu para o perfil Registrador Acadêmico,
agrupadas como no menu. O último grupo traz as que não estão no menu e
se abrem por um card do Painel. As que ainda não têm página neste manual
aparecem sem link.
