# Gestor Setec

O Gestor Setec administra o PNP Gestor: publica conteúdos, organiza as
categorias e controla os grupos de permissão. Cadastrar e alterar grupos
é só dele e do Administrador. Fora do PNP Gestor, cadastra os Operadores
SETEC em [Gerenciamento de Usuários]({{site.baseurl}}/documentacao/manual-do-usuario/central-de-atividades/gerenciamento-de-usuarios)
e abre [Unidades]({{site.baseurl}}/documentacao/manual-do-usuario/configuracoes-iniciais/unidades) pelo Painel para
editar unidades de toda a rede.

## O que você enxerga

O perfil não é vinculado a uma instituição: alcança a rede inteira. Na
edição de uma unidade, a tela habilita só os campos que este perfil pode
alterar. Em Gerenciamento de Usuários, você vê só as pessoas que são
Operador SETEC, e esse é o único papel que você atribui e retira.

## Suas telas

Estas são as telas que aparecem no menu para o perfil Gestor Setec,
agrupadas como no menu. O último grupo traz as que não estão no menu e
se abrem por um card do Painel. As que ainda não têm página neste manual
aparecem sem link.
