# Administrador

O Administrador é o perfil que opera a plataforma. Ele vê quase todas as
telas do menu. Por isso, esta página não repete a lista inteira: para as
telas que ele divide com outros perfis, use o [índice do manual]({{site.baseurl}}/documentacao/manual-do-usuario/),
organizado pelos grupos do menu.

## Telas só do Administrador

Estas telas aparecem no menu apenas para este perfil. As que ainda não
têm página neste manual aparecem sem link.

- **Central de Atividades → [Monitoramento de Tarefas]({{site.baseurl}}/documentacao/manual-do-usuario/central-de-atividades/monitoramento-de-tarefas)**
- **Central de Atividades → [Manutenção do Sistema]({{site.baseurl}}/documentacao/manual-do-usuario/central-de-atividades/manutencao-do-sistema)**
- **Cadastros Gerais → [Matriz de Permissões]({{site.baseurl}}/documentacao/manual-do-usuario/configuracoes-iniciais/matriz-permissoes)**
- **Cadastros Gerais → [Sessões de suporte]({{site.baseurl}}/documentacao/manual-do-usuario/configuracoes-iniciais/sessoes-de-suporte)**
- **Cadastros Gerais → [Configurações]({{site.baseurl}}/documentacao/manual-do-usuario/configuracoes-iniciais/configuracoes)**
- **Cadastros Gerais → [Municípios]({{site.baseurl}}/documentacao/manual-do-usuario/configuracoes-iniciais/municipios)**

## Telas que o Administrador não tem no menu

Quatro telas são de perfis específicos e não aparecem no menu do
Administrador:

- **Inconsistências → [Inconsistências de Ensino]({{site.baseurl}}/documentacao/manual-do-usuario/inconsistencias/inconsistencias-de-ensino)**
- **Inconsistências → [Inconsistências de Gestão de Pessoas]({{site.baseurl}}/documentacao/manual-do-usuario/inconsistencias/inconsistencias-de-gestao-de-pessoas)**
- **Microdados → [Fila de Homologação]({{site.baseurl}}/documentacao/manual-do-usuario/microdados/fila-de-homologacao)**,
  do [Gestor de Área Temática]({{site.baseurl}}/documentacao/manual-do-usuario/perfis/gestor-area-tematica)
- **Microdados → [Aprovação de Microdados]({{site.baseurl}}/documentacao/manual-do-usuario/microdados/aprovacao-de-microdados)**,
  do [Reitor]({{site.baseurl}}/documentacao/manual-do-usuario/perfis/reitor)
