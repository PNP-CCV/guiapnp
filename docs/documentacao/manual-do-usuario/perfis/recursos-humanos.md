# Recursos Humanos

O perfil Recursos Humanos acompanha os dados de pessoal da sua
instituição — servidores e cargo-emprego — e resolve as inconsistências
de gestão de pessoas. Concluir e restaurar inconsistências não é deste
perfil.

## O que você enxerga

O perfil é vinculado a uma instituição. As telas mostram os dados dessa
instituição.

## Suas telas

Estas são as telas que aparecem no menu para o perfil Recursos Humanos,
agrupadas como no menu. O último grupo traz as que não estão no menu e
se abrem por um card do Painel. As que ainda não têm página neste manual
aparecem sem link.
