# Diretor-Geral

O Diretor-Geral não tem tela no menu. Pelo Painel, abre
[Unidades]({{site.baseurl}}/documentacao/manual-do-usuario/configuracoes-iniciais/unidades),
onde vê e edita a sua unidade.

## O que você enxerga

O perfil é vinculado a uma unidade: em Unidades, aparece só ela. Na
edição, a tela habilita só os campos que este perfil pode alterar.

## Suas telas

Esta é a tela que ele abre por um card do Painel:

- [Unidades]({{site.baseurl}}/documentacao/manual-do-usuario/configuracoes-iniciais/unidades)
