# Operador SETEC

O Operador SETEC publica e organiza os conteúdos do PNP Gestor. Em
Grupos de Permissão, só consulta: vê os grupos para escolher qual
associar a um conteúdo. Cadastrar e alterar grupos é do Gestor Setec.

## O que você enxerga

O perfil não é vinculado a uma instituição: alcança a rede inteira.
