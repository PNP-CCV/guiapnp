# Pesquisador Institucional

O Pesquisador Institucional acompanha os dados de ensino da sua
instituição e trata as inconsistências de ensino: resolve, conclui e
restaura. Acompanha também o progresso e a certificação de conclusão das
inconsistências, baixa os dados institucionais, cadastra pessoas e
atribui papéis.

## O que você enxerga

O perfil é vinculado a uma instituição. As telas mostram os dados dessa
instituição.
