# Diretor Executivo

O Diretor Executivo não tem tela no menu. Pelo Painel, abre
[Unidades]({{site.baseurl}}/documentacao/manual-do-usuario/configuracoes-iniciais/unidades),
onde vê e edita as unidades da sua instituição.

## O que você enxerga

O perfil é vinculado a uma instituição. Na edição de uma unidade, a
tela habilita só os campos que este perfil pode alterar.

## Suas telas

Esta é a tela que ele abre por um card do Painel:

- [Unidades]({{site.baseurl}}/documentacao/manual-do-usuario/configuracoes-iniciais/unidades)
